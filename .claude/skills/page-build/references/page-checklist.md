# Page checklist

- [ ] Matches design.md section order and Figma frame
- [ ] One H1; headings in order (no skipped levels)
- [ ] Primary CTA visible above the fold on mobile
- [ ] All text from content/<page>.md; no placeholder text
- [ ] Images: dimensions set, alt text, lazy below fold, modern format
- [ ] Loading, empty, and error states render
- [ ] Keyboard: every interactive element reachable and operable; visible focus
- [ ] Color contrast AA on every text/background pair
- [ ] Metadata and structured data present and valid
- [ ] No raw style values (lint passes)
- [ ] No console errors or failed network requests
- [ ] Lighthouse mobile: performance at or above profile target, accessibility at or above 95
- [ ] Works at 390px, 768px, 1280px
