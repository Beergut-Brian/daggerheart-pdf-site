# site-profiles

Read only the reference file for the chosen profile:

- `references/ecommerce.md`: online stores, subscriptions, bundles, inventory sync
- `references/local-service.md`: contractors, clinics, salons, lawn care, trades, anything booking quotes or appointments in a service area
- `references/nonprofit.md`: donations, volunteers, programs, events
- `references/brochure.md`: small business or organization site with no transactions
- `references/portfolio.md`: creative or professional showcase

Every profile shares the generic skills: design-system, page-build, content-writing, seo-setup, qa-launch, deploy-staging, status-reporting, analytics-tracking. The reference file adds what is specific.

## Shared defaults

- Pages every site has: home, about or story, contact, privacy policy, 404.
- Every site has: analytics with consent handling, a contact path, accessible navigation, Open Graph images.
- Every form has spam protection and a confirmation state.
