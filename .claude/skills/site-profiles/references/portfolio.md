# Profile: portfolio

Main visitor action: view work, then get in touch.

## Required facts
Who it is for (clients, employers, galleries), work samples with permission to show, categories, bio, contact preference, any case-study structure.

## Default pages
Home (selected work), work index with filters, one page per project or case study, about, contact, plus shared defaults.

## Extra skills
`page-build` image guidance matters most here: responsive images, lazy loading, lightbox or gallery component. `forms-and-leads` for contact. `seo-setup` with Person or CreativeWork schema.

## Phase order
0 Foundation → 1 Design and pages → 2 Work content and images → 3 QA and launch.

## Done tests
Largest Contentful Paint under 2.5s on a project page with images; every project has title, role, outcome, and at least one image with alt text; contact form delivers.
