# imagery

## Order of preference

1. Client photos from `asset-intake`. Real work, real people, real premises convert best for local service and nonprofit sites.
2. Licensed stock with a recorded license (source, license type, URL) in `assets/LICENSES.md`. Choose images that look local and specific; avoid obvious stock faces.
3. Generated images only for abstract, illustrative, or background use, never to depict the client's actual work, team, or customers as if real. Label them as generated in `LICENSES.md`. Generation runs through Kaden's existing image pipeline when available; otherwise request from Kaden.
4. Icons from one consistent set, licensed, recorded.

## Preparation

- Crop to each component's aspect ratios from the design system; export at the sizes the responsive image rules need; modern format plus fallback.
- Strip metadata; add descriptive filenames; write alt text that describes content, or empty alt for decorative images.
- Open Graph image per page type, 1200x630, with the brand and the page title, generated from a template.
- Keep originals in `assets/photos/originals/`; derived files are regenerated by a script.

## Rules

No image without a recorded license or permission. No competitor imagery. No generated images presented as the client's real work. Faces of customers only with permission in `asset-intake`.
